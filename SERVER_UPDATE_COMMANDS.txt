================================================================================
          SPARETRACK SERVER UPDATE & DEPLOYMENT COMMANDS
================================================================================

OPTION A: QUICK ONE-LINER (COPY & PASTE ALL AT ONCE IN POWERSHELL)
--------------------------------------------------------------------------------
git pull origin main; docker exec -t sparetrack-app php artisan migrate --force; docker exec -t sparetrack-app php artisan optimize:clear; docker restart sparetrack-app sparetrack-worker sparetrack-reverb sparetrack-nginx


================================================================================
OPTION B: STEP-BY-STEP COMMANDS (RUN ONE BY ONE)
================================================================================

1. Pull Latest Code from GitHub:
   git pull origin main

2. Run Safe Database Migrations:
   docker exec -t sparetrack-app php artisan migrate --force

3. Clear and Refresh Laravel Caches:
   docker exec -t sparetrack-app php artisan optimize:clear
   docker exec -t sparetrack-app php artisan config:cache
   docker exec -t sparetrack-app php artisan route:cache
   docker exec -t sparetrack-app php artisan view:cache

4. Restart Docker Containers:
   docker restart sparetrack-app sparetrack-worker sparetrack-reverb sparetrack-nginx


================================================================================
OPTION C: DATABASE BACKUP (RUN BEFORE OR AFTER UPDATE)
================================================================================

Create a Timestamped PostgreSQL Backup:
   docker exec -t sparetrack-postgres pg_dump -U sparetrack_user -d sparetrack -c > backups/sparetrack_backup_latest.sql


================================================================================
OPTION D: VERIFY SERVER STATUS & HEALTH
================================================================================

1. Check running Docker containers:
   docker ps

2. Check Laravel logs if needed:
   docker exec -t sparetrack-app tail -n 50 storage/logs/laravel.log
