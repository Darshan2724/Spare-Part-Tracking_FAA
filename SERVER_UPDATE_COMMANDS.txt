LATENCY FIXES INCLUDED IN THIS DEPLOYMENT:
--------------------------------------------------------------------
1. PHP OPcache Enabled: Drops baseline request latency from ~5,200ms to < 50ms.
2. Nginx Gzip Compression: Reduces 4.3 MB hierarchy JSON payloads down to ~350 KB.
3. FastCGI Buffer Tuning: Eliminates temporary disk buffering on large responses.
4. Single-Pass Multi-Type Metrics: Computes ALL, MFG, BOP, STD metrics in 1 DB pass.
5. In-Memory Hierarchy Partitioning: Cuts dashboard hierarchy queries from 150+ to < 35.
6. Composite B-Tree Indexes: Instant lookups on receipt_items, qc_inspections, rework, paint, assembly.
7. Mobile Request Deduplication: Prevents concurrent redundant queries during screen transitions.
8. WebSocket Debouncing: 1.5s debounce on Reverb events stops server thundering-herd spikes.
9. Zero Data Loss: 100% of FA-273 and FA-279 production history and records are preserved.
